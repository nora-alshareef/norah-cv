Caracal
Founder — caracal.solutions
View docs →

Identity infrastructure for verification and liveness, built as a real developer-facing API. Two proprietary recognition models (Malma 1 for speed, Malma 2 for accuracy), a liveness engine that catches presentation attacks, and a self-hosted deployment path for customers who can't send biometric data to the cloud.

  • Three completely separate auth schemes with zero fallback between them — API keys for machine-to-machine gallery ops, Supabase-backed JWTs for account management, a dedicated admin secret.
  • /verify and /liveness ship unauthenticated and unrate-limited by design, so integration testing has zero friction before a customer commits.
  • Entitlement checks are never cached — every request re-verifies, fail-closed on any doubt.
  • Self-hosted deployments run identical model weights to the cloud API, license-gated rather than downgraded.

Ibram — National Digital Signature Platform
Founder · Sole Architect · Lead Developer — SDAIA / NIC
ibram.nic.gov.sa →

Saudi Arabia's national platform for legally-binding digital signatures. I built the signing engine myself, then hired and interviewed the team that scaled it. Business case, cryptography, infrastructure, and network — all mine to design.

  • Built the core RSA/ECDSA signing engine, integrated directly against Saudi's PKI Signing CA — no third-party signing vendor.
  • Negotiated and commissioned the HSM contracts myself, then set up the HSMs and network path to them.
  • Now processes 5,000+ signing transactions a day and has signed 300,000+ documents in production.
  • Later extended the platform with a dedicated document-signing CA (TCA) — architected and set up personally.

Saudi National PKI — Migration & Public SSL
System Architect — SDAIA / NIC
SDAIA CA →

Supervised the migration of Saudi Arabia's national PKI from NCDC to SDAIA's datacenter — understanding NCDC's existing infrastructure, the PKI itself, and the specific structure of the Saudi PKI hierarchy, then designing the new environment it would live in.

  • Designed the system architecture for new datacenter zones — root room, server racks, network segmentation — and wrote the full migration plan.
